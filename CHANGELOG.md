# Changelog

## 0.1.0

- First official PHP SDK for the Jurono legal services API, requiring PHP 8.2 or later.
- All 765 operations across 84 services from the API 2.0.0 public OpenAPI snapshot, including form-builder endpoints.
- Bearer tokens, API keys, JSON requests, multipart uploads, and binary downloads.
- Response envelope access, structured HTTP errors, and separate network errors.
- Reproducible generation, contract coverage tests, real HTTP tests, and release archives with runtime dependencies.
